# Iate de Todos

Site estático responsivo da plataforma **Iate de Todos — Ouvir, Cuidar e Transformar**.

## Site

Após a ativação do GitHub Pages, a publicação fica disponível em:

**https://cairesmachado-svg.github.io/Iate_bsb/**

## Estrutura

- `index.html` — página completa, responsiva, em HTML/CSS puro.
- `.github/workflows/pages.yml` — publicação automática no GitHub Pages.

## Atualização

Alterações enviadas à branch `main` disparam uma nova publicação automaticamente.
